# Sokuou 文档库

> 原语供其用，正典明其意，经验促其进。

本文档库面向所有使用 Sokuou 的开发者与 Agent，不以特定应用、框架或仓库组织为前提。
目标是让调用者自然沿用 Sokuou 的思路构建动画，并把真实使用中的所得带回公共知识与原语。

## 从何处读起

| 所求 | 文档 | 读后应知 |
|---|---|---|
| 理解 Sokuou 的动画思路 | [SOKUOU.md](SOKUOU.md) · 正典 | 状态如何经 progress 解析为视觉状态；原语与宿主的边界 |
| 在自己的项目中接入，或让 Agent 实现动画 | [INTEGRATION.md](INTEGRATION.md) · 调用指南 | 原语选择、更新与渲染、打断与退出、经验总结 |
| 报告问题、分享经验、贡献改进 | [BACKFLOW.md](BACKFLOW.md) · 回流指南 | 何种经验值得回流，以何种证据、通过何种路径参与 |
| 修改 Sokuou 本仓 | [../AGENTS.md](../AGENTS.md) · 工作流守则 | 本仓的代码、验证与提交约定 |
| 查 API 签名与实现细节 | 源码 rustdoc（`cargo doc --open`） | 当前版本实际提供的方法与参数 |
| 追溯旧设计 | [archive/](archive/) | 历史背景；不作现行调用依据 |

初次使用，依次读正典与调用指南；遇到所得，再按回流指南整理。
修改本仓时，另须遵循本仓工作流守则。

## 文档各司其职

- **正典**定概念与契约。语义有变，随代码一同修订。
- **调用指南**给默认实践。项目可以据交互、品牌、可访问性与宿主约束作选择，并留下理由。
- **回流指南**连接经验与改进。Issue、使用报告、文档修正与代码 PR 都是有效回流。
- **本仓守则**约束在本仓的修改，不自动成为所有消费方仓库的开发制度。
- **历史文档**仅供追溯，不覆盖现行文档。

参数建议与单个项目的使用经验，不自动成为所有调用者的强制规范。
正典描述预期契约，源码与验证结果反映当前版本的实际行为；二者冲突时，应记录差异并修正，不可假定尚未实现的能力已经存在。

## 让 Agent 自然沿用

依赖库中的文档不一定会被调用方 Agent 自动发现。
在调用方的 `AGENTS.md`、`CLAUDE.md` 或等效项目指引中，放置一次可达的入口即可，后续动画任务沿此入口工作：

```text
本项目使用 Sokuou 构建状态驱动动画。
动画任务先读 Sokuou 的 docs/README.md，并按其中指引阅读正典与调用指南。
使用 state → progress → resolve → render 的结构；宿主持有实例、推进时间并请求重绘。
任务完成时，简述原语选择、打断与退出验证、调用所得；可复用的问题或改进按 BACKFLOW.md 整理。
```

将上述文档位置替换为本项目实际可访问的路径或链接；git 依赖未将源码置于工作区时，可链接到所用版本的仓库文档。
记录所用版本或提交，避免拿最新版文档推断旧版 API。
无需为每个动画任务重复整套规则，也无需仅为使用 Sokuou 修改其源码。
